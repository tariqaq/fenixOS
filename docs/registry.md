# App registry

New app? Start from `fenixos-app-template.zip` (`templates/app/`): it builds the files and the filled manifest this page describes.

The PC app lists apps from the registry in this repo. Each app lives in its own GitHub repo; the registry only holds its manifest. Plan: `docs/PLAN.md` §3.7.

## Layout

- `registry/apps/<id>.json`: one manifest per app (format below).
- `registry/index.json`: generated by `python tools/registry.py` from the manifests. CI runs `python tools/registry.py --check`, which fails when a manifest is invalid or the index is out of date.
- The PC app reads `https://raw.githubusercontent.com/tariqaq/fenixOS/main/registry/index.json`.
- v0.1 ships with an empty registry: this repo has no real apps, only the test fixture in `tools/sample-app` (§1.2 of the plan).

## Manifest

```json
{
  "id": "io.github.tariqaq.sample",
  "name": "Sample",
  "description": "Test fixture: CPU and memory cards, a slider, a switch and a button",
  "version": "0.1.0",
  "min_fenixos": "0.1.0",
  "color": "teal",
  "icon": "puzzle-piece",
  "repo": "https://github.com/tariqaq/fenixOS",
  "board": { "url": "https://github.com/tariqaq/<repo>/releases/download/v0.1.0/app.fxp", "sha256": "<64 hex>", "size": 1612 },
  "pc": { "url": "https://github.com/tariqaq/<repo>/releases/download/v0.1.0/app.exe", "sha256": "<64 hex>", "size": 412000, "elevated": false },
  "permissions": ["system-stats"],
  "settings": [
    { "key": "interval", "type": "choice", "label": "Update every", "default": "2", "options": [ { "value": "1", "label": "1 s" }, { "value": "2", "label": "2 s" } ] }
  ]
}
```

| Field | Rule |
|---|---|
| `id` | `io.github.<owner>.<name>`; letters, digits, `.` `-` `_`; ≤ 48 bytes. Must equal the board package's id |
| `name` | Tile label, ≤ 24 bytes |
| `description` | One line, ≤ 100 bytes (Add app list, App settings header) |
| `version`, `min_fenixos` | `x.y.z`. `version` must equal the board package's version |
| `color` | A tile token (`gray` `indigo` `blue` `teal` `green` `orange` `red` `purple` `pink`) or `#RRGGBB` |
| `icon` | A Phosphor icon name (fill weight), for the PC tile. The board tile uses the package's own icon |
| `repo` | `https://github.com/tariqaq/<repo>`: shown as Source |
| `board` | Required. Board package (`.fxp`): `url`, `sha256` (lowercase hex), `size` in bytes (≤ 64 KB) |
| `pc` | Optional. The PC half (win-x64 `.exe`): `url`, `sha256`, `size`, `elevated` (true: Windows asks for admin each time it starts) |
| `permissions` | What the PC half does, from the list below, each once. Shown before Add and on the App settings page |
| `settings` | The app's options, rendered by fenixOS (below). Values go to the PC half |

**Allowed sources.** Download URLs must start with `https://github.com/tariqaq/`. A local registry (below) may also use paths relative to its own folder.

**Checks on install.** The PC app downloads each file, checks size and sha256, and then checks that the package's id and version match the manifest. Any mismatch stops the install and nothing is kept.

### Permissions

| Id | Shown as |
|---|---|
| `keys` | Press keys and shortcuts |
| `media` | Change volume and control media |
| `system-stats` | Read CPU, memory and other system stats |
| `network` | Use the network |
| `files` | Read and write files |
| `programs` | Start other programs |

Two rows are added from the manifest itself: "Runs its own helper program while switched on" when there is a `pc` part, and "Asks for administrator rights each time it starts" when `pc.elevated` is true.

### Settings

Every entry has `key` (letters, digits, `_` `-`; ≤ 32, unique), `type`, `label` (≤ 40 chars) and, except `button`, a `default`. Corrected (P45): the key and label limits were missing here (`tools/registry.py` checks them).

| `type` | Extra fields | Value sent to the PC half |
|---|---|---|
| `toggle` | | `true` / `false` |
| `slider` | `min`, `max`, `step`, `unit` (optional) | number |
| `choice` | `options`: list of `{value, label}` | the option's `value` (string) |
| `text` | `placeholder` (optional), `max_len` (default 100) | string |
| `button` | | none: pressing it sends a `button` message with the key |

## Local registry (testing)

`FENIX_REGISTRY=<folder>` makes the PC app read `<folder>/index.json` instead of GitHub. Relative URLs in it resolve against that folder.

`pwsh tools/sample-app/build.ps1` builds the test fixture (board package + PC half) and writes a local registry to `target/sample-registry/`. It uses `python tools/registry.py --local <out> <manifest> --board <fxp> [--pc <exe>]`, which copies the files, fills in `url`, `sha256` and `size`, and writes the index.
